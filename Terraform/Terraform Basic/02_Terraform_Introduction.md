# Terraform Introduction

- **Course module vs Terraform module**: A course module is a learning section; a Terraform module is a reusable collection of infrastructure configuration.

- **Infrastructure as Code (IaC)**: Terraform lets you define cloud resources, such as EC2 instances, in files instead of creating them manually. This makes infrastructure easier to adjust, reproduce, and scale.

- **Orchestration vs configuration management**: Terraform primarily provisions infrastructure; tools such as Ansible primarily configure machines and their software. Upcoming lessons explain when to use each.

- **Practical Terraform usage**: The course will cover everyday workflows and tips for using Terraform effectively, beyond simply deploying resources.
