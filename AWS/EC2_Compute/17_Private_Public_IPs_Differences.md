# Private vs Public IP (IPv4) Differences

### Public IP
- Identifies a device on the **public internet**.
- Must be **globally unique**.
- Examples include a public web server IP or your home router's external IP.
- Can often reveal an approximate location such as country or city.

### Private IP
- Used only **inside a private network**, such as a home or company network.
- Only needs to be unique **within that network**.
- The same private IP ranges can be reused in completely separate networks without conflict.
- Devices with private IPs are not directly reachable from the public internet.

### Key Difference
```text
Public IP   → globally unique and internet-facing
Private IP  → locally unique and internal to a private network.
```
