# IPv4 VS IPv6

IP addresses identify devices on a network, and the two main versions are **IPv4** and **IPv6**.
- **IPv4** is the older and still very common format, e.g. `10.160.10.240`. It uses four numbers separated by dots, with each value ranging from `0-255`.
- **IPv6** was introduced because the world was running out of available IPv4 addresses as more devices connected to the internet.
- IPv6 supports vastly larger number of addresses and is increasingly important for modern networks and IoT devices.

### Key Idea
```text
IPv4 → older, shorter, widely used
IPv6 → newer, much larger address space
```
IPv6 exists mainly to solve the adress exhaustion problem that IPv4 eventually ran into.
