# Amazon Compute

**Compute** is the processing power used to run applications. In AWS, you don't manage the physical servers yourself. AWS provides the infrastructure and you choose how your workloads run.

### Main AWS compute options:

1- **EC2 (Elastic Compute Cloud)**: virtual machines where you control the OS, software, and configuration.

2- **Containers**: lightweight application environment, commonly run with:
- **ECS**: AWS's container orchestration service
- **EKS**: AWS-managed Kuberneter

3- **Serverless - Lambda**: serverless compute where AWS runs and scales your code automatically when triggered. and you pay for actual execution time.

4- **High Availability & Scalability**: key cloud concepts that apply accross EC2, containers, and serverless services.

In short, AWS compute gives you different ways to run applications depending on how much control, flexibility, and automation you need.
