# Amazon EC2

**EC2** is AWS's **Infrastructure as a Service (IaaS)** offering that lets you rent and run virtual machines in the cloud.

### **It mainly consists in the capability of**:
- You can spin up **VM (Virtual Machines)**, choose the **operating system, instance size, and configuration** based on your needs.
- **EBS (Elastic Block Store)** provides persistent block storage for EC2, similar to attaching a virtual hard drive.
- **ELB (Elastic Load Balancing)** distributes incoming traffic across multiple EC2 instances.
- **ASG (Auto Scaling Groups)** automatically adds or removes EC2 instances based on demand.

The key idea: EC2 gives you flexible virtual servers that can be combined with **storage, load balancing, and auto scaling** to build scalable cloud applications.
