# AWS Introduction

2002-2003: AWS began as Amazon's internal infrastructure, before Amazon realized it could offer that infrastructure to other companies as a service.

2004-2006: AWS launched publicly, starting with SQS `Simple Queue Service` , then expanding with major services like S3 `Simple Storage Service` and EC2 `Elastic Compute Cloud` .

2007 onward: AWS expanded globally, including Europe, and grew from an internal Amazon system into a major cloud computing platform.
