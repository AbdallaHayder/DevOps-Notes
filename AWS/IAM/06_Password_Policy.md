# Password Policy

AWS lets you configure password rules to strengthen IAM user security, such as:
- Minimum password length and required character types
- Password expiration
- Preventing reuse of old passwords
- Allowing users to change their own passwords

For personal AWS accounts, use **a strong password + MFA**. In larger production environments, organisations often prefer **SSO (Single Sign-On)** or other centralized authentication methods instead of relying heavily on passwords.
