# IAM Security Tools

AWS provides two useful IAM tools for reviewing and improving account security:

* **IAM Credentials Reports (account-level)**:

    an account-wide report showing IAM users and credential details, such as whether they have access keys, MFA enabled, and password activity.
* **IAM Access Advisor (user-level)**:

    shows which AWS servies a specific user or role can access and when those services were last used.

These tools help you audit accees and enforce **least privilege** by identifying old, unused, aor unnecessary permissions.
