# AWS CKI (Command Line Interface)

The **AWS CLI** lets you manage AWS services directly from your terminal instead of using the Management Console.
- It interacts with AWS service APIs using commands.
- You can manage resources such as **S3 buckets, EC2 instances, and more**.
- It is especially useful for **automation and scripting**, helping reduce repetitive manual work.
- Example commands include `aws s3 cp` to upload files and `aws s3 ls` to list S3 content.

In short, the AWS CLI is a faster and more automation-friendly way to work with AWS.
