# Permissions

IAM permissions define **what users and groups are allowed or denied from doing in AWS** through **policies**, which are written in **JSON**.

- Policies specify allowed or denied **actions** on AWS resources, such as viewing EC2 instances or CloudWatch metrics.
- A key security principle is **least privilege**: only give users the permissions they actually need.
- Avoid granting unnecessary access, especially powerful actions like deleting resources or chaning configurations.
---
The goal is to keep AWS access **secure, controlled, and limited to what each user needs to do their job**.
