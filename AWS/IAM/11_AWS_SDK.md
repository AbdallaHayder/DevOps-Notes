# AWS SDK (Software Development Kit)

The **AWS SDK** lets applications interact with AWS services directly through code using language-specific libraries.

- AWS provides SDKs for languages such as **Python, JavaScript, Java, Go, PHP, and C++**.
- Developers can use SDKs to work with services like **S3, EC2, DynamoDB**, and others without using the AWS Console.
- SDKs are useful for building applications that need to automatically communicate with AWS services.
- The Python AWS SDK is called **Boto3**, and the AWS CLI is built using AWS SDK functionality underneath.

In short, the SDK lets you integrate AWS directly into your application code.
