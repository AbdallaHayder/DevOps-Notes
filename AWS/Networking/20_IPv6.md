# What is IPv6?

**IPv6** is the successor to IPv4 and was created mainly because IPv4 has a limited address space of about **4.3 billion addresses**.
- IPv6 provides around **3.4 × 10³⁸ addresses**, giving an enormous amount of address space.
- It is designed to support the continued growth of internet-connected devices.

### IPv6 Format
IPv6 addresses:
- use **hexadecimal** characters: `0–9` and `A–F`
- use **colons** **(`:`)** instead of dots
- are much longer than IPv4 addresses

**Example**:

`2001:0db8:85a3:0000:0000:8a2e:0370:7334`

Long sequences of zeros can be shortened using `::`.

### IPv6 in AWS
The lecture emphasizes that IPv6 resources in AWS use globally routable IPv6 addresses, so you need appropriate security controls rather than relying on private-address behavior like with IPv4.

### Why IPv6?
- Solves IPv4 address exhaustion
- Supports massive future growth
- Important for modern networking and large-scale infrastructure

### Key Idea
**IPv4 = limited 32-bit address space**
**IPv6 = vastly larger 128-bit address space designed for the future of networking**
